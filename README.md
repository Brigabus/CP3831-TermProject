# CP3831-TermProject
Monkey Soccer Unity Term Project

A small project for our CP3831 Graphics and Game-Dev course

Control your monkey and try to kick the ball into the opposing team's goal!
You can Tackle other players to make them drop the ball.
Goalies are controller simultaneously to your monkey using the same up / down inputs!

Player 1 Controls:
Movement: WASD
Sprint: Left Shift
Kick / Tackle: Left Ctrl

Player 2 Controls:
Movement: Arrow Keys
Sprint: Right Shift
Kick / Tackle: Right Ctrl

GamePad Controls:
Movement: Left Stick
Sprint: X Button (X-input) / Square (PS Controller)
Kick / Tackle: A Button (X-Input) / Cross (PS Controller)
Dance: B Button (X-Input) / Circle (PS Controller)
[Note: Dancing is only working on controllers]
[Punching another player when they are dancing will knock them out for some time]

Additional Controls:
Close Game: Escape
Spawn Extra Ball: P (Multiple balls is broken, don't do this)
Enable Players 3 and 4: O (Players 3 and 4 can only be controlled when 3 or 4 gamepads are connected)
